## How to use
1. Morning: pick 3 tasks from this list → write them in today's daily note with hours estimate
2. Work through the day
3. End of day: fill actual hours, move unfinished tasks to tomorrow or Kanban
4. Update this table when tasks change (add/remove/reprioritize)

## Course rule
PCB course 30 min first thing, every work day. Other courses happen when you work on those projects — not a daily block.

## Rules
- Pull from this list, don't invent new tasks mid-day (except emergencies)
- If a task bounces 3+ days → split it or kill it
