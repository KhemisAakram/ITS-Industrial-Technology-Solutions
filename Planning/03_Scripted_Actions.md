# Scripted Actions — Simple Checklists

> Never think about what's next. Run the script.

## Wake-up (3 questions — 1 min)

```
Q1  Energy?
    fresh → 3 real tasks today
    medium → 2 tasks + 1 light task
    tired → 1 task + rest

Q2  What's the ONE thing that moves the most money or the biggest project?
    → That's Task #1

Q3  Anything blocking progress? (parts, client reply, machine down)
    → If yes, pick the best unblocked task instead
```

Then fill today's note: 3 tasks + estimate hours. Done.

## Workshop session (per task)
- [ ] State the ONE outcome this block must produce
- [ ] Tools/parts ready before starting
- [ ] Work until done or block ends
- [ ] Stuck >30 min → note blocker, switch task
- [ ] Snap 1–2 photos if client-visible

## Client visit / site job
- [ ] Confirm appointment + address the day before
- [ ] Kit: multimeter, laptop, tools, parts, camera
- [ ] Written diagnosis + quote before starting
- [ ] Log hours + revenue same evening

## Report / defense session
- [ ] Pick the chapter/section
- [ ] Gather sources first (10 min)
- [ ] Write freely 25 min → break 5 min → edit
- [ ] Move finished section to "done" in [[Final_Report_Defense]]

## Shutdown (2 min — end of day)
- [ ] Log hours + revenue in daily note
- [ ] Move unfinished tasks → tomorrow or [[ITS_Kanban|Kanban]]

## Weekly review (Thursday evening or Friday)
- [ ] Count billable hours + revenue; compute avg yield
- [ ] Mark milestone gates met/missed ([[01_Milestones]])
- [ ] Pull next week's 3 priorities → [[02_Task_Bank]]
- [ ] File weekly note in `06_Weekly_Notes`

## Monthly review (last work day of month)
- [ ] Score 4 projects: SOMIK / Workshop / Clients / Report
- [ ] Update progress % on each project note
- [ ] Adjust milestones if >2 days behind
