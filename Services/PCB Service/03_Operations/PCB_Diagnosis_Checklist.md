# PCB Diagnosis Checklist

## Customer Info
- [ ] Customer name & phone
- [ ] Company / facility
- [ ] Date received

## Board Info
- [ ] Board type / model
- [ ] Equipment it came from
- [ ] Physical condition (photos taken?)
- [ ] Known symptoms (per customer)

## Visual Inspection
- [ ] Burn marks / charred components
- [ ] Cracked PCB traces
- [ ] Bulging / leaking capacitors
- [ ] Corrosion or moisture damage
- [ ] Loose or broken connectors
- [ ] Solder joint cracks (cold joints)
- [ ] Missing components
- [ ] Blown fuses / fusible resistors

## Power Test
- [ ] Short circuit on power rails (VCC-GND)
- [ ] Input voltage present at connector?
- [ ] Voltage regulator output(s) correct?
- [ ] Power LED / indicator works?

## Signal / Functional Test
- [ ] Clock signal present (if applicable)
- [ ] Relay / contactor clicks?
- [ ] Output signals correct?
- [ ] Communication ports functional (RS232/485, etc.)?
- [ ] Display / indicators respond?

## Diagnosis Result
- [ ] Repairable — estimate given
- [ ] Not repairable — explained to customer
- [ ] Requires replacement part — ordered / quoted
